# Code Of Conduct

## Our Standard

This project expects discussions, reviews, and issue reports to stay factual, respectful, and technically grounded.

Examples of expected behavior:

- critique code and decisions, not people
- provide reproducible evidence when reporting bugs or regressions
- stay clear about assumptions, limits, and tradeoffs
- keep collaboration open to contributors with different levels of experience

Examples of unacceptable behavior:

- harassment, personal attacks, or discriminatory language
- bad-faith review behavior, including deliberate misrepresentation of evidence
- publishing private credentials, tokens, or local machine details without consent
- spam, intimidation, or repeated off-topic disruption

## Scope

This applies to repository discussions, issues, pull requests, and benchmark or release conversations carried out in project spaces.

## Enforcement

Project maintainers may remove content, close threads, or restrict participation when behavior violates this policy.

For security-sensitive or private concerns, use the process in `SECURITY.md`.
