## 发布口径指引

- hybrid 的公开表述应以“质量不降”为先，只有验证集上的平均输出质量持平或更好时，才成立 release claim。
- 主要优化目标是耗时，而不是 token。
- token 表现按 tier 分化，应该引用下面两次重型测试的分层结果，不要对外宣传成普遍性的 token 优化。
